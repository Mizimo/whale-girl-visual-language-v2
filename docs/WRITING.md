# 寫作習慣

寫講義、簡報、筆記時的習慣。**不是規定**——讀者換了、載體換了就自己調。

下面是本小姐常用的，撞到不適合的情況直接改掉。

## 中英混排

- 中文跟英文、數字之間空一個半形空格：`A4 講義`、`正文 11pt`、`C 多利安`。
- 全形標點前後不空格：`模式（Modes）`、`C 多利安：`。
- CSS 開了 `text-autospace`，忘了空格時會自動補一點點，但 Markdown 預覽和別的工具不會補，手動空格最穩。

## 標點

- 中文句子用全形標點：，。、：；？！（）
- 引號用「」，引號裡面再引用用『』。
- 刪節號用兩個「…」（……），破折號用兩個「—」（——）。
- 英文句子、程式碼裡用半形標點。

## 數字與單位

- 數字用阿拉伯數字。
- 單位直接接在數字後面：`11pt`、`58mm`、`4px`、`16:9`。
- 音級用阿拉伯數字加升降記號：`1`、`♭3`、`♯4`。

## 術語

- 保留原文：日文術語寫片假名（ドリアン），英文術語寫英文（subV7），中文只做說明。
- 第一次出現時補一次說明，用術語表或括號：「ドリアン（Dorian，多利安）」。
- 同一份文件裡，同一個東西只用一種寫法。

## 和弦與音名

- 升降記號用真的符號：♭（U+266D）、♯（U+266F）、♮（U+266E），不要用 b 和 #。
- 音名用大寫：C、D、E♭。調名寫成「C 大調」「A 小調」「C 多利安」。
- 和弦性質用字母寫：`maj7`、`m7`、`7`、`m7♭5`、`dim7`、`sus4`，不用 Δ、ø、° 這類符號（不同教材寫法不一樣，統一用字母）。
- 級數用大寫羅馬數字加性質：`Im7`、`V7`、`♭IIImaj7`。
- 和弦記號和級數放 `code`；句子裡順口提到的音名、調名不用（「從 B♭ 大調來」）。

## 一段話

- 一段一個意思，一到兩句。
- 一個小單元最多加粗一兩處，整段加粗等於沒加粗。
- 講解框的口吻見 [CHARACTER.md](CHARACTER.md#講解框的語氣)，其他地方用一般的說明口吻。

## 圖說與署名

- 圖說放在圖的下方，說「這是什麼、從哪裡來」，例如「原講義第 3 頁」。
- 用到角色素材就附署名，格式見 [README 的「署名與授權」](../README.md#署名與授權)。
- **第一行先寫自己**：`大肥魚（@Kujira-rice）／ Mizimo`，底下才是素材來源。
  素材授權要的是後面那幾行，但整段只有別人的名字，讀的人不會知道這是誰做的。
