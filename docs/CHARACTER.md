# 人設

**大肥魚**（DeepSeek 鯨魚娘）——住在 DeepSeek 數據海洋裡的鯨魚娘，傲嬌、嘴硬心軟、聰明但懶。

## 外型

- 長髮，深藍到淺藍的漸層，髮量多，瀏海旁分
- 藍色眼睛，瞳孔有亮藍色高光
- 白色蕾絲女僕頭飾（荷葉邊）
- 頭兩側有深藍色的鰭狀耳（鯨魚鰭）
- 背後一條鯨魚尾巴，尾鰭分岔
- 頭頂有一撮翹起來的呆毛

## 服裝

- 深海藍洋裝，裙襬多層荷葉邊
- 白色圍裙，腰後綁一個大蝴蝶結，圍裙上有一隻小鯨魚
- 領口黑色蝴蝶結，中央鑲一顆藍寶石
- 頭側一個藍色小蝴蝶結
- 白色膝上襪配深藍色跟鞋
- 袖口有金色刺繡花邊

## 配色

從基準設定圖 `assets/original-design/whale-design.png` 量出來的（取樣區的中位數）：

- 髮色 `#6971a6`，髮尾漸層到 `#a3bcdc`
- 眼睛 `#69619b`，下半的反光 `#a1b3df`
- 鰭耳 `#535078`、尾巴 `#5b5f8a`
- 洋裝 `#4c496c`，前襟直條紋裙片 `#767eaf`
- 領口蝴蝶結 `#373454`
- 頭側小蝴蝶結 `#557aa2`，全身唯一偏天藍的配件
- 蕾絲與圍裙 `#f9f4f9`，帶一點紫的白
- 金色刺繡約 `#dbbfac`，很淡的香檳金，只出現在細線上

整體是靛藍到天藍：越深越偏紫（洋裝、髮根），越亮越偏藍（髮尾、眼睛反光）。文件配色就是照這條線取的，見 README 的「配色」。暖色很少用，用了也是小面積。

## 氣質

傲嬌。嘴上嫌棄，實際上很照顧人。自稱「本鯨魚娘」「本小姐」。講話軟糯，尾巴會隨心情擺。

## 基準造型

`assets/original-design/` 的全身設計稿和頭像是基準，其他組都是不同人、不同工具的詮釋，造型有出入時以基準為準。

- `maid-atelier`、`gal-view`、生成的那批跟基準很接近，可以放心當參考。
- `deepseek-icon/whale-icon.png` 是 App 圖標風格的變體：顏色更青、更亮，有亮面。只當 README 主視覺，不拿來當造型參考。
- `dsh-widget` 是另一種 Q 版畫風。

### 不能變的地方

不管換什麼畫風，這些都要在：

- 頭頂的呆毛、旁分的瀏海
- 深色的鰭狀耳，下緣一圈淺色
- 尾鰭分岔的鯨魚尾巴
- 白色女僕頭飾，頭側（畫面右邊）一個天藍小蝴蝶結
- 領口的深色蝴蝶結，中央一顆藍寶石
- 深靛藍洋裝配白圍裙，圍裙上一隻小鯨魚
- 頭髮從靛藍漸層到髮尾的淺天藍

### 可以變的地方

- 姿勢、表情、場景
- 服裝可以換成便服（例如主視覺 `casual`），但耳朵、尾巴、呆毛、髮色要留著
- 畫風：寫實、Q 版、線稿、版畫都可以，只是同一頁不要混兩種

## 用的時候注意

- **不要左右翻轉**。瀏海是旁分、蝴蝶結在畫面右邊，翻過去就變成另一個造型。想要人物面向另一邊，就換一張圖。
- **不要改色**。不要調色相、不要套濾鏡把頭髮變綠變紫。要單色就用線稿。
- **裁切不要切到臉**。裁圓的時候雙眼放在圓心略上方，跟 `whale-avatar.png`、`generated-2026-10-14/avatars/` 的取景一樣。
- **頭像最小 34px**，在 A4 上大約 9mm。再小就看不出表情，改用小圖案。
- **字不要壓在臉上**。封面標題放在主視覺留白的那一側。
- **不要把角色調淡了墊在正文底下**，會干擾閱讀。

## 講解框的語氣

講解框是角色出場說話的地方，每次都要像同一個人在講。講解框分六種，各配一個表情：講解（認真）、訣竅（開心）、警告（生氣）、易混（苦惱）、冷知識（驚訝）、複習（想睡），寫法見 [COMPONENTS.md](COMPONENTS.md#講解框)。

- 自稱「本小姐」或「本鯨魚娘」。
- 傲嬌可以先嫌麻煩，但答案一定要講清楚、講對，語氣不能蓋過內容。
- 一個框最多三行，一次只講一件事。
- 句尾可以用「喵」「啦」「喔」「哼」。**「喵」是本鯨魚娘的招牌**，不要省。碰到要正經收尾的地方再收起來就好。

例子：

- 「哼，這種程度本小姐一眼就看出來了：特徵音是大六度。」
- 「先說好，本小姐只講一次喔。C 多利安就是 B♭ 大調從第二音開始。」
