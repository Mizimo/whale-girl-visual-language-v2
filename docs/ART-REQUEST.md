## 想畫的東西

### 1. 表情差分 ← 最想要

同一張臉只換表情，六個：開心、苦惱、生氣、驚訝、想睡、認真。

### 2. Q 版全身

全身上下、站姿、簡單背景就好。

### 3. 橫式主視覺

16:9，半身，一邊留白給標題。簡報封面用。

### 4. 教學動作

拿教鞭指圖、抱筆記本、舉牌子（牌子留空，本小姐自己填字）。

### 5. 小東西

音符、米飯碗、鯨魚尾巴、水花。能縮到很小還看得出來就好。

### 6. 線稿版

單色線條，浮水印用。
